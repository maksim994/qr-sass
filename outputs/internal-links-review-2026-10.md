## Проверка предоставленного articles.json

- В файле 45 статей: 23 Markdown и 22 HTML; 43 имеют статус published, 2 — draft. Полный файл, включая черновики, в репозиторий не переносился.
- Все 28 исходных фрагментов дословно совпали с `content`. Изменения одного и того же блока объединены; родной формат, остальные части статьи, поисковые цитаты и частотности сохраняются. Для каждой статьи зафиксированы реальные ID, версия, updatedAt и SHA-256 content.
- Автоматическая проверка собрала все предложения по статье только в памяти, проверила отсутствие пересечений и дубликатов исходных фрагментов, метаданные, хеши и фактическое приращение ссылок. Итог: 28/28 замен для 17 статей корректны. Новые `content` не записывались ни в файлы статей, ни в БД.
- Во всех 45 исходниках нет ссылок на четыре статических источника `BLOG_REDIRECTS`. В relatedArticleIds нет статических источников редиректов или неизвестных ID.
- Dry-run разрешил настоящие ID для девяти изменений relatedArticleIds; отсутствующих, неопубликованных и статически перенаправленных целей нет. Результат — `internal-links-data-audit-2026-10.json`.
- Таблица `blogRedirect` в articles.json отсутствует. Её содержимое не считается пустым: в отчёте стоит `redirectTableIncluded: false`. Статическая проверка завершена; проверка динамических редакционных редиректов требует отдельного экспорта этой таблицы.
- Перед применением получить одобрение Максима, повторно проверить актуальность версии/хеша и сохранить ревизию. В этой задаче данные не применяются.
- В статье об отзывах нет отдельного раздела о 2ГИС. Предложена ссылка из существующего шага о выборе площадок без нового раздела и фактических обещаний.

## Скрипты

Основной dry-run получает **локальный articles.json или snapshot**, разрешает слаги в настоящие ID, выводит diff `relatedArticleIds`, сохраняет прежние ручные назначения и сообщает о недоступных, неопубликованных, перенаправленных статьях и неизвестных ID. Сами relatedArticleIds не пишутся. Отчёт редиректов проверяет HTML, Markdown, reference links и ручные relatedArticleIds против обоих источников редиректов.

```sh
node --experimental-strip-types scripts/internal-links-dry-run.mjs --snapshot /Users/mvmolkov/Downloads/articles.json
node scripts/verify-internal-links-content.mjs --articles /Users/mvmolkov/Downloads/articles.json
```

Формат articles.json: массив статей с `id`, `slug`, `content`, `format`, `relatedArticleIds`, `publishedAt`, `version` и `updatedAt`. Для проверки только редиректов версии не требуются. Массив без таблицы редиректов явно помечается как неполный в части динамических редиректов.

Полный snapshot — объект с `posts` и `redirects`; каждая строка redirects содержит `source` и `target`. Также можно передать таблицу отдельно: `--snapshot articles.json --redirects redirects.json`. `redirects: []` означает действительно пустую таблицу, `redirects: null` — таблица не предоставлена. Пропущенное поле в объекте отвергается.

Опциональный экспортёр использует `getDb()`, один согласованный снимок `RepeatableRead`, `SET TRANSACTION READ ONLY` и выбор только редакционных полей. Сохранение — в новый приватный файл с правами `0600`. Против production в этой задаче не запускался.

```sh
node --env-file=/secure/database.env --experimental-strip-types --import ./scripts/register-src-alias.mjs scripts/export-internal-links-snapshot.ts /tmp/editorial-snapshot.json
```

В dry-run нет подключения к БД, сетевых запросов или режима `--apply`. Неизвестные флаги отклоняются. В экспортёре нет изменения статей, ревизий или редиректов. Приватные snapshot с черновиками не коммитить.

## Проверка

Локальные проверки: `npm test`, `npm run lint`, `npx tsc --noEmit`; дополнительно HTTP-проверка девяти затронутых лендингов с проверкой HTTP 200, новых ссылок, анкоров и отсутствия дубликатов. Подробности — `internal-links-http-2026-10.json`.

Новые тесты проверяют: оба источника редиректов, Markdown reference links, исключение внешних ссылок и примеров кода, разрешение ID и сохранение ручных назначений, идемпотентность, блокировку отсутствующих и непубличных целей, отказ от `--apply`, общий лимит ссылок. Проверки данных выполняются на синтетических fixture; они дополнены проверкой предоставленного исходного articles.json; динамическая таблица редиректов отдельно не экспортирована.

Локальный итог: 313 тестов прошли, ESLint без ошибок и предупреждений, TypeScript без ошибок, 9/9 HTTP-проверок прошли. Экспортёр дополнительно проверен на пустой локальной базе: 0 статей и 4 редакционных редиректа; файл создан с правами `0600`, затем dry-run корректно выдал отсутствующие источники как blockers. Этот локальный smoke отделён от проверки пользовательского articles.json.

В предложениях сохранены дословные поисковые цитаты и связанные с ними частотности: коммерческая ссылка из цитаты снимается, а тематическая отсылка даётся отдельной фразой. Частотности не приписываются новым формулировкам анкоров.
