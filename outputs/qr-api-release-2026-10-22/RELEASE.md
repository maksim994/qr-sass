## Что опубликовано

- Bearer-ключи `qrs_api_` в кабинете: имя, явно выбираемые scopes `qr:read`, `qr:write`, `stats:read`, отзыв, однократное отображение секрета. Хранится SHA-256; лимит запросов атомарно учитывается в PostgreSQL.
- QR API для динамических URL: создание, список/карточка, смена назначения без замены напечатанного QR, PNG/SVG, агрегированная статистика по дням и устройствам, метка `bitrix_module`.
- Доступ на Бесплатном/Про/Бизнесе в пределах общих квот кабинета. На production чтением текущего Free-тарифа подтверждены **PNG и SVG**.
- Объединённая публичная OpenAPI **1.5.0** с сохранением API статей. Прежние `qre_` и редакционные ключи сохраняют свои отдельные контракты.
- Страница ключей закрыта от аналитики, рекламных SDK и custom head; ответы новых API, включая ошибки и изображения, private/no-store.

Статические текст, Wi-Fi и телефон остаются задачей локального модуля Битрикса. `Idempotency-Key` в v1 отсутствует: модулю передано требование сверять список после обрыва POST перед новым созданием. [Контракт](../../docs/QR-API-V1.md), [дополнение к ТЗ модуля](../../docs/tz-bitrix-module-api-v1.md).
