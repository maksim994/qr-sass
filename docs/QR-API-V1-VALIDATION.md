## Границы

- Это QR API для динамических **URL**, со сменой назначения без перепечатки. Статические URL, текст, Wi-Fi и телефон создаются локально модулем Битрикса.
- Idempotency-Key не входит в v1. После обрыва POST интеграция сначала проверяет список; слепой повтор может создать второй код.
- Счётчик запросов использует фиксированные минутные окна, а не скользящее окно.
- Реальный модуль 1С-Битрикс здесь не устанавливался; контракт и пример подключения в `docs/QR-API-V1.md`.
- В build остаётся прежнее предупреждение Next о переименовании middleware в proxy. Зависимости и это соглашение не менялись.
- В production ничего не отправлялось и не выкатывалось. SMTP, платежи и workers для проверки не запускались. Собственные тестовые серверы и PostgreSQL-контейнер после приёмки остановлены и удалены.
