- 204 теста, TypeScript, целевой ESLint и production build прошли.

В Coolify сохранены `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET`, `YANDEX_REDIRECT_URI`, `YANDEX_AUTH_ENABLED=true` как runtime-переменные. Значения ключей не записаны в Git и отчёты.

При выключенном флаге, отсутствующих ключах или несовпадающем callback кнопок нет; прямой `/register/yandex` возвращает к регистрации по email. - На настоящем dev-сервере с поддельными Host и X-Forwarded-Host все четыре auth-ответа сохранили публичный origin из APP_URL. На production-сборке кандидата с синтетическими OAuth-ключами авторизация ведёт к oauth.yandex.ru, callback соответствует публичному адресу, ошибки/режим привязки возвращаются на публичный login; секрет не попадает в HTML.
