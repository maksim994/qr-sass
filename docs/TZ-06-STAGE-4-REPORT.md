# ТЗ-06: этап 4 — редиректы и изображения

## Реализовано

- `/admin/blog/redirects`: список, создание 301, подтверждение удаления, комментарий/автор/дата; события в общем журнале. Четыре прежних редакционных 301 перенесены в БД с теми же путями/назначениями. Два системных правила 308 показаны отдельно и защищены.
- Нормализация внутренних путей; запрет занятых опубликованных/запланированных страниц, QR и системных путей, циклов и цепочек с подсказкой конечного адреса. Транзакционная блокировка сериализует создание правил с публикацией/расписанием статьи.
- GET/POST `/api/v1/redirects` с прежним Bearer-ключом и журналом; удаления через API нет.
- Новые обложки и изображения текста: обязательный alt до загрузки, MIME по байтам, 10 MiB/40 млн пикселей, WebP до 480/960/1600 без увеличения, корректная ориентация, width/height, srcset/sizes. GIF — первый кадр. Используется прежний S3.
- POST `/api/v1/articles/{id}/images`: загрузка, вставка безопасного figure в Markdown или смена обложки, обязательная version. Повторная проверка версии после загрузки; конфликт очищает только созданные этой операцией файлы.
- PATCH того же URL меняет alt по точному URL с версией/автором; старый HTML сохраняется без массовой конвертации и без изменения кодовых примеров.
- Старые изображения/обложки не переписываются. Право публикации через API не добавлено. OpenAPI 1.1.0 и [примеры curl](ARTICLE-API.md) обновлены.
