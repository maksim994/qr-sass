# ТЗ-06, этап 4: редиректы и изображения

Владелец принял этап 3 и разрешил этап 4 20.10.2026; действующий API-ключ проверен владельцем. Новые статьи через API остаются черновиками, публикация — отдельное действие в админке.

## До реализации

Четыре редакционных 301 заданы в `BLOG_REDIRECTS`/next.config; системные www и trailing slash имеют 308. Картинки загружаются в существующий S3 в одном WebP, alt требуется лишь перед вставкой в текст. Готовых srcset и размеров нет.

Добавляем список редиректов в админке (старые правила видны, поведение сохраняется), новые 301 в БД, создание/удаление с журналом. API-ключ может читать/создавать, удалять нельзя. Нормализуем путь/регистр/слеши; защищаем рабочие страницы и системные маршруты, включая все QR. Циклы и цепочки отклоняются с предложением конечного адреса. Запись сериализуется в БД для защиты от параллельного создания A→B/B→A. Системные правила остаются неизменяемыми.

Для новых изображений: обязательный alt до загрузки, проверка содержимого/размера, WebP 480/960/1600 без увеличения, исходные размеры и srcset. Хранилище прежнее; существующие файлы и статьи не переписываем. Результат содержит безопасный figure для Markdown. API загружает изображение к существующей статье с проверкой version, обновляет обложку либо вставляет figure и создаёт версию; отдельная операция меняет alt существующего изображения с версией/журналом. Валидация и санитизация сохраняются.

До выпуска: тесты редиректов/гонок/санитайзера/изображений, OpenAPI и curl; desktop/mobile, backup/restore и baseline QR/data/blog, проверка на изолированной восстановленной копии, затем тот же ресурс Coolify с точным SHA. Реальные статьи и ключи не используем для тестовых записей.
