# Дополнение к ТЗ модуля 1С-Битрикс: форматы и повторы QR API

Дата: 22.10.2026. Применяется к этапу подключения динамических QR-S-кодов. Статическая локальная версия модуля от этого этапа не зависит. **QR API выпущен на production**, SHA `c2d4b0b576cc8f525f77fb0fc357ebd5cd6010c4`; схема: `https://qr-s.ru/api/v1/openapi.json` (1.5.0).

Основной технический контракт: [QR-API-V1.md](QR-API-V1.md). Это дополнение к полному ТЗ модуля, а не его замена.

## Форматы на Бесплатном

В текущей реализации стандартный Бесплатный тариф предоставляет **PNG и SVG**, как и Про/Бизнес. Подтверждено `PLAN_DEFAULTS.FREE.limits.exportFormats` и HTTP-проверкой обоих форматов на синтетическом Бесплатном кабинете.

Индивидуальные/архивные условия и административные изменения могут отличаться. Если SVG возвращает 403 при действующем ключе с `qr:read`, модуль один раз запрашивает PNG для того же QR id. При успешном PNG ошибка SVG пользователю не показывается. Новый код для смены формата не создаётся. Ошибки ключа (401), лимита (429), сети и сервера обрабатываются отдельно; неуспех PNG нельзя скрывать.

## Восстановление после обрыва создания

В API v1 нет `Idempotency-Key`. Таймаут после POST не доказывает, что QR не сохранён.

1. До POST сохранить локально идентификатор операции, данные элемента, стабильное имя и targetUrl. Исключить параллельное создание для одного элемента.
2. После обрыва оставить операцию в состоянии сверки. Не выполнять автоматический повтор POST, в том числе по повторному нажатию кнопки.
3. Сначала получить список своих QR через `GET /api/v1/qr`, пройти все страницы по `nextOffset`. Восстановить `id` и `shortUrl` единственного однозначного совпадения по сохранённым данным операции и `source=bitrix_module`.
4. При недоступности списка или неоднозначных совпадениях сохранить состояние сверки. Если код пока не найден, повторить чтение позднее: исходный запрос ещё может выполняться. Только после подтверждения отсутствия созданного кода допустимо новое создание. Одного пустого ответа списка для этого недостаточно.

Имя и URL не гарантируют уникальность на стороне API; стабильный идентификатор операции можно включать в имя (до 120 символов). На Бесплатном дубликат одного товара может занять оба динамических слота.

## Приёмка динамического этапа

- На стандартном Бесплатном работают оба формата. При имитации запрета SVG получается PNG того же id, без ошибки SVG и без дополнительного POST.
- При имитации «сервер создал QR, ответ потерян» модуль находит его в списке, сохраняет существующий id и не создаёт второй QR.
- При ошибке списка, незавершённом исходном запросе или нескольких кандидатах повторный POST автоматически не отправляется.
